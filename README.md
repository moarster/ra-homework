# Дашборд мониторинга карьерных самосвалов (тестовое задание)

## Материалы решения

Markdown файлы решения лежат в папке [result](result), они самодостаточны и намеренно краткие, как того требуют временн*ы*е ограничения задания. Автор рассчитывает, что подробное обсуждение предполагается на озвученной "защите". 

## Прототип дашборда

Работать должны все доступные в UI функции, но это не гарантируется. Единственная заведомая заглушка — значок текущего пользователя (не активно)

Решение не предназначено для разворачивания на сервере и доступе с нескольких клиентов.

### Запуск локально 

Предпочтительно для heavy-simulation. Требуется Node.js 22+.

```bash
pnpm dev
```

Доступ — http://localhost:5173

### Запуск в Docker

Не требует Node

```bash
cd docker
docker compose up
```

Доступ — http://localhost:3001
